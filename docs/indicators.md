# v1 行情指标

主图查询、策略组件登记、配置回测和实时决策共用 `finance_api::indicators`。内核是 Rust 库模块，可增量消费闭合 bar，也可从同一批 bar 重建状态。finance-api 和 F2 编译器直接调用该模块，Python 策略运行器通过同一版本的本地 `finance-strategy` 子进程调用。Nautilus 继续提供回测引擎、行情模型和 catalog。

## 版本与计算口径

下表中的 ID 都以 `indicator.` 开头并固定为 `@1.0.0`。`GET /api/v1/indicators` 返回完整 ID、输入、参数、输出单位和版本化计算规则。`SMA` 和 `MA` 在界面上指同一简单均线，组件 ID 为 `indicator.sma@1.0.0`。表中的首值对应从序列起点计数的闭合 bar 数。`n` 为 `period`。

| ID 中的指标名 | 输入与算法 | 首值所需的 bar |
| --- | --- | --- |
| `sma` | 收盘价的最近 `n` 根算术均值 | `n` |
| `ema` | 收盘价。前 `n` 根的算术均值为种子，此后平滑系数为 `2/(n+1)` | `n` |
| `rsi_wilder` | 收盘价差分正负分别取非负涨跌幅。前 `n` 次变化分别用均值作种子，此后以 `1/n` 平滑。结果为 `100 × 平均涨幅/(平均涨幅+平均跌幅)` | `n+1` |
| `bollinger` | 收盘价，中央线为 `n` 根 SMA，上下轨为均值加减两倍总体标准差（`ddof=0`） | `n` |
| `macd` | 收盘价，快速 EMA 减慢速 EMA 为 MACD 线。信号线取 MACD 的 EMA，柱值为两线之差。信号线同样用首窗均值作种子 | 三列同在 `slow_period + signal_period - 1` 根就绪 |
| `atr` | 高、低、前收盘。真实波幅取高低差及高价、低价分别距前收盘的绝对差三者的最大值。首根用高低差。前 `n` 根波幅均值为种子，此后以 `1/n` 平滑 | `n` |
| `vwap` | 高、低、收盘和成交量，以 `(high+low+close)/3` 为每根代表价，按成交量加权。提供方的 `trading_day` 改变时重置 | 当日首根累计成交量为正时 |
| `close_return` | 最近收盘除以 `n` 根前的收盘减一，单位为比率 | `n+1` |
| `realized_volatility` | 最近 `n` 次单根简单收益率的样本标准差（`ddof=1`），单位为比率，无年化系数 | `n+1` |
| `volume_sma` | 最近 `n` 根成交量算术均值，沿用输入数量单位 | `n` |

`period` 一般为 1 至 2520，Wilder RSI 和实现波动率最少为 2。Wilder RSI 保留 F2 使用的 `field: close`。MACD 的 `fast_period`、`slow_period`、`signal_period` 的上限均为 2520，快速周期须小于慢速周期，三个周期均为正整数。VWAP 无参数。布林带输出 `middle`、`upper`、`lower`，MACD 输出 `macd`、`signal`、`histogram`，其余指标输出 `value`。

窗口按收到的有效 bar 推进。缺口会保留，价格与成交量均不补值。相邻观测的收盘变化可跨过缺口，调用方按数据覆盖要求判断是否可用。完成预热后，RSI 无涨跌历史、VWAP 当日累计量为零、收益率分母为零时，相关值为 `undefined`。OHLCV 源字符串保留原精度。

## 数值域与舍入

输入 OHLCV 使用 `rust_decimal::Decimal`，系数最多 96 个二进制位（最多 29 位十进制有效数字），绝对值上限为 `79228162514264337593543950335`。去掉小数尾零后，每个字段最多 27 位小数，最小非零绝对值为 `10^-27`。价格允许有符号，成交量允许零或正数。同一窗口可混合不同量级。27 位小数覆盖 [F1 十进制文本](market-protocol.md#精确值与时钟) 的全部合法输入，HTTP 投影同时遵守 F1 的文本规则。

内核在更新状态前逐字段检查小数位。超限返回 `NumericInputOutOfRange`。时间区间、OHLC 关系或负成交量错误返回 `InvalidBar`。批量、增量、前缀回放和预览共用校验。

- SMA、成交量均线及布林中轨使用精确的定点窗口和。VWAP 精确累加 `(high+low+close) × volume` 和成交量，再除以 `3 × 累计成交量`。区间收益率直接用整数比值计算。各项从精确比值舍入到输出精度。
- EMA、ATR 和 MACD 使用 64 位小数的定点状态。种子取首窗均值，之后按 `((d-w) × 旧值 + w × 当前值) / d` 递推，每次除法按 64 位小数半数取偶舍入。EMA 的 `w=2`、`d=n+1`，ATR 的 `w=1`、`d=n`。MACD 的快慢 EMA 之差以内部精度进入信号 EMA。EMA 周期为 1 时当前值权重为 1，输出为当前收盘价在输出精度下的舍入值。
- Wilder RSI 的涨跌状态保留 64 位小数，每次衰减向下取整到该定点精度。平盘时涨跌按共同系数衰减，输出保持上一比值。再次变动时用已衰减的状态和本次价差计算新比值。
- 布林带从原始收盘价的精确窗口矩计算总体方差。实现波动率的单根收益率先按 64 位小数半数取偶舍入，再从这些值的精确窗口矩计算样本方差。单根收益率的绝对值及窗口内收益率之和的绝对值必须在 `Decimal` 幅度以内。

各输出按最接近值舍入，恰好一半时取偶数。普通输出先舍入到 12 位小数，再以 `Decimal` 精确编码，允许去掉尾零。布林上下轨及实现波动率从其未舍入的平方根公式取能编码的最大小数位数，最多 12 位。这样较宽的轨道不会因其精度降低而改变中轨。分散度相关输出的未舍入绝对值须在 `Decimal` 幅度以内。展示值不回流到计算状态。

收益率或分散度的幅度超限，或舍入结果无法按本节规则编码时，内核返回 `NumericOverflow`。任何指标报错都保留整条序列在上一根已提交 bar 后的状态，前缀回放同样执行这些检查。

## 时钟、价格基准与回放

每个引擎实例消费一条固定标的、源、产品、周期和价格基准的序列。上游提供 bar 的起止时间和所属交易日。交易所日历负责本地交易日及提前收盘，`24X7` 按 UTC 日界。内核使用提供的交易日标签，不从 UTC 时间推断美股交易日。原始价和已在上游按明确口径归一化的序列均可计算，复权及成交量换算由输入提供方完成。同一实例的价格口径和单位须一致。

增量调用 `IndicatorEngine::push_closed`，批量调用同一模块的 `batch`，二者走相同状态更新。按时间递增提交闭合 bar。`preview` 用上一根闭合后的状态计算一根未闭合 bar，结果带 `provisional`，每次预览都从同一闭合状态开始。`warmup` 描述是否已取得首值所需的输入，与 bar 的闭合状态独立。策略只接收已经闭合且在决策时刻已可用的输入。

重启时用相同的组件版本与参数，从相同序列起点回放闭合 bar。`advance_closed` 执行与 `push_closed` 相同的计算、检查和提交，省略输出构造。EMA、RSI 和 MACD 等递推指标依赖种子，有限滚动窗口不能保证重建旧状态。处理 F1 更正时，输入方先按目标位置和修订顺序解析闭合历史，再按更新后的序列重放。策略回放按 `first_available_ts` 筛选当时可见的版本。配置回测和实时决策从 [StrategyBundle](strategy-bundle.md) 取得组件版本、参数和所选输出列，以各自的回放时钟和点时闭合历史推进同一内核。主图使用已发布的展示序列。

算法、输入或舍入口径变化须注册新组件版本。用合成事件检查批量、增量和重启路径见 [指标测试](../crates/finance-api/tests/indicators.rs)。主图选择数据范围、版本和预览选项见 [HTTP API](api.md#主图行情与指标)。
