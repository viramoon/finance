# ADR-0004：Yahoo 拆股归一化日线的官方研究准入

状态：已采纳

日期：2026-11-26（issue 现场记录日期）

适用范围：finance 的单标的官方历史回测、Yahoo 转换与研究快照

关联：[finance issue #25](https://github.com/viramoon/finance/issues/25)

## 背景

IBM 2024 的 Yahoo 源报价带有浮点残留，精确等于美分的旧准入使该示例无法转换。IBM 长样本又包含多个拆股事件。Yahoo 的 `indicators.quote` 可能已经归一化，跨拆股的供应商价格也可有亚美分位数。源 `adjclose` 派生因子可能混入分红调整。当前官方撮合按美分报价，研究引擎没有原始持仓拆股处理流程。

## 决策与备选

保留经审核的原始无拆股入口，并在 `0.00002 USD` 容差内清除 Yahoo 浮点残留。跨拆股时增加经审核的供应商统一拆股股份口径，要求存档截止日一致、保留源拆股事件及审核证据。最后一个相关拆股日前的 OHLC 可以精确保留亚美分报价。模拟继续使用美分执行报价，信号与净值标记采用保存的收盘价。两种入口均排除现金分红。

逐个拆股日调整原始持仓与现金需要另一个执行模型。直接乘除源价格可能对已归一化的行情重复调整。强制把所有供应商报价写成整分会损失拆股后价格精度。使用 `adjclose` 派生因子会改变本研究的价格收益口径。继续只准入无拆股区间则会截断有相关公司行为的长历史。

## 影响与验证

新增归一化报价与公司行为标识，使用现有数据集清单字段。现有原始快照和导入入口可继续使用。归一化导入验证 CSV 哈希及其血缘，并保留审核文件。仓库内构造样本用来验证整分容差、拆股口径和官方作业；实际长归档需要按 [研究回测手册](../historical-backtest.md) 审核。结果按归一化股份单位解释，早期研究成交价或持仓股数不代表当时的挂单价或股数。

## 后续工作

若需求扩展到按当时股份口径模拟持仓变更、现金分红或公司行为可得时点，用独立方案定义数据要求、引擎行为及验证方法。
