# ADR-0034：为永续上下文分配行情流版本 2.0

状态：已采纳

日期：2026-11-27

适用范围：finance 的 F1 行情事件与能力、F3 投影和下游读取

关联：[finance #34](https://github.com/viramoon/finance/issues/34)

## 背景

F5 需要把资金费率、未平仓量和标记价格作为同一时点的观测发布到 MarketIngress。F1 v1.0 在 Rust 和 Python 均按封闭的消息列表解码。供应商的上下文帧还缺少交易所时间，这与 v1.0 的市场数据时间要求不同。

## 决策与备选

为 `perpetual_context` 事件及声明该能力的产品分配 2.0。上下文允许空交易所时间，使用原始十进制字符串。盘口、成交与 gap/reset 等控制事件继续用 1.0，经同一套 F3 WAL 与投影传输。按每条记录声明的版本选择 schema。将三个字段塞入 v1.0 状态或成交会改变已有消息的语义。给上下文另建日志会产生第二套许可和恢复流程。

## 影响与验证

v1.0 导出文件逐字节保持一致。生成器输出独立的 v2 事件及能力 schema，并通过合成样本验证 Rust 和 Python 往返与 Parquet 投影。F3 的 WAL 帧和 Parquet 列保持兼容。读取含上下文的产品前，使用支持该事件版本的 reader 和 projector。

## 后续工作

F6 及下游在接入上下文时识别 v2.0。下游如只消费盘口和成交，可按 channel 筛选相应流，处理各流的 v1.0 控制消息。
