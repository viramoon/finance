# Parquet 数据目录

行情使用 Nautilus data catalog 的 Parquet 文件，不额外部署时序数据库。实际目录默认 `/home/box/fertile/data/catalog`，从配置读取，不把行情文件提交到 git；本仓库的 catalog/ 只存约定。

规划按数据类型、标的、时间范围管理，保留来源、时区、精度、schema 与去重依据；collector 负责写入，回测和分析按明确时间范围读取。TBD：分区方式、并发写入规则和 Nautilus 版本对应目录格式，实施前验证，不能手工修改 catalog 内部格式。
